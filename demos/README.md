# Feature Demos

This directory contains HTML files for manual testing and demonstration of specific features and components.

## Files

- `domainscorepanel.html` - Domain score panel component demo
- `time.html`, `timev2.html`, etc. - Time-related feature demonstrations

## Purpose

These are standalone HTML pages used for:
- Manual testing of individual components
- Feature demonstrations
- Debugging specific functionality
- Visual verification of UI elements

Unlike the automated tests in `../tests/`, these require manual interaction and observation.
