KEY POINTS:

📌 DEPLOYMENT:
   - Copy public/ contents to web root
   - Include src/ in same directory level
   - EXCLUDE: test/, .docs/, node_modules/

📌 IMPORT PATHS:
   From public/index.html: "../src/app.js"
   From src/app.js: "../public/icons/..."
   From test/pages/: "../../src/app.js"

📌 HOW PATHS WORK:
   public/index.html (relative to root)
   └─ ../src/app.js      ← Goes up one level then into src/
   └─ ../public/icons/   ← Goes up one level then into public/

📌 QUICK NAVIGATION:
   App Code.............. src/
   Static Assets......... public/
   Tests................ test/
   Documentation......... .docs/
   Dev Config............ . (root - eslint, prettier, etc)
